# Nitsche dynamic-rupture station conventions (spec I3)
# frame: nhat = pin reference normal (0, -1, 0), up = (0, 0, 1)
#        shat = up x nhat / |up x nhat| = (1, 0, -0), dhat = shat x nhat = (0, -0, -1)
# pin: orientation propagated, pinned by the reference normal; plus side = side nhat points into
# columns: t slip1 slip2 V1 V2 tau1 tau2 sigma_n psi T p
#   slip1 = delta.dhat (SCEC v-slip)      slip2 = delta.shat (SCEC h-slip)
#   V1    = V.dhat     (SCEC v-slip-rate) V2    = V.shat     (SCEC h-slip-rate)
#   tau1  = -T.dhat    (SCEC v-shear-stress, Pa)  tau2 = -T.shat (SCEC h-shear-stress, Pa)
#   sigma_n = -T.nhat (compression positive, Pa); T = total traction on the face with normal nhat
#   delta = u(+) - u(-), V = d delta/dt (SCEC slip definition)
#   psi: state variable psi
#   thermal pressurization: sigma_n = -T.nhat - (p - p_ini), the effective normal stress the law sees (TPV105)
#   T = temperature on the fault (K), p = pore pressure on the fault (Pa), p_ini = 8e+07 Pa, T_ini = 483.15 K
