## 2. Governing Physics: BP5-QD

### 2.1 Problem Statement

BP5-QD is a 3D quasi-dynamic earthquake cycle problem. An elastic half-space
($x_1 \in (-\infty, +\infty)$, $x_2 \in (-\infty, +\infty)$, $x_3 \in [0, \infty)$
depth-positive-down) contains a vertical planar fault at $x_1 = 0$. The fault
supports rate-and-state friction. Far-field tectonic loading drives right-lateral
strike-slip at plate rate $V_p$.

**Coordinate mapping** (SCEC abstract to code/mesh):
- SCEC $x_1$ (fault-normal) = code $Y$ (fault at $Y = 0$)
- SCEC $x_2$ (along-strike) = code $X$
- SCEC $x_3$ (depth, positive down) = code $-Z$ ($Z = 0$ at surface, negative downward)

### 2.2 Governing Equations

**Momentum balance** (quasi-static, no inertia):

$$\nabla \cdot \boldsymbol{\sigma} = \mathbf{0} \quad \text{in } \Omega$$

where $\boldsymbol{\sigma}$ is the Cauchy stress tensor for a linear isotropic elastic solid:

$$\boldsymbol{\sigma} = \lambda \, \text{tr}(\boldsymbol{\varepsilon}) \, \mathbf{I} + 2\mu \, \boldsymbol{\varepsilon}$$

$$\boldsymbol{\varepsilon} = \frac{1}{2}\left(\nabla \mathbf{u} + (\nabla \mathbf{u})^T\right)$$

**Boundary conditions:**
- **Dirichlet (far-field):** $u_X = \text{sgn}(Y) \cdot V_p \, t / 2$ on far-field faces (attr 5)
- **Natural (free surface + bottom):** $\boldsymbol{\sigma} \cdot \mathbf{n} = \mathbf{0}$ on top ($Z = 0$) and bottom (attr 1)
- **Fault (interior interface at $Y = 0$):** $\text{slip} = [\![ \mathbf{u} ]\!]$ is prescribed by the ODE

**Fault stress balance** (quasi-dynamic with radiation damping):

$$\tau_\text{total} = \tau_\text{pre} + \tau_\text{elastic}$$

$$|\tau_\text{total}| = \sigma_n \, f(|V|, \psi) + \eta \, |V|$$

$$\mathbf{V} \text{ is anti-parallel to } \boldsymbol{\tau}_\text{total}$$

where $\eta = \mu / (2 c_s)$ is the radiation damping coefficient.

**State evolution** (aging law in $\psi$-space):

$$\psi = f_0 + b \ln\!\left(\frac{V_0 \, \theta}{D_c}\right)$$

$$\dot{\psi} = \frac{b \, V_0}{D_c} \exp\!\left(-\frac{\psi}{b}\right) - \frac{b}{D_c} |V|$$

which is the transformed form of $\dot{\theta} = 1 - |V|\,\theta / D_c$.

## 3. Weak Form → Discrete Form → Code: Term-by-Term

This section is the core of the guide. It traces every term from the
continuous PDE through the weak form, into the discrete matrix/vector
equations, and finally to the exact code lines that implement it.

### 3.1 Starting Point: Strong Form

$$\nabla \cdot \boldsymbol{\sigma}(\mathbf{u}) = \mathbf{0} \quad \text{in } \Omega$$

$$\boldsymbol{\sigma} = \lambda \, \text{tr}(\boldsymbol{\varepsilon}) \, \mathbf{I} + 2\mu \, \boldsymbol{\varepsilon}, \qquad \boldsymbol{\varepsilon} = \tfrac{1}{2}(\nabla \mathbf{u} + (\nabla \mathbf{u})^T)$$

### 3.2 Weak Form and Integration by Parts

Multiply the strong form by a test function $\mathbf{w}$, integrate over
the domain (split into elements $K$), and integrate by parts
element-wise. This produces:

$$\sum_K \int_K \boldsymbol{\sigma}(\mathbf{u}) : \boldsymbol{\varepsilon}(\mathbf{w}) \, dV \;-\; \sum_K \int_{\partial K} (\boldsymbol{\sigma}(\mathbf{u}) \cdot \mathbf{n}) \cdot \mathbf{w} \, dS \;=\; 0$$

The first sum is the **volume integral** (becomes Term V).
The second sum contains **boundary integrals** over every element face.
In DG, we classify each face and apply specific DG operators
(averages, jumps, penalties) to obtain the complete bilinear form.

### 3.3 Complete DG Weak Form: All Terms Defined

**Notation used throughout this section:**

- $\{v\} = (v^- + v^+)/2$ — average across a face
- $[\![ v ]\!] = v^- - v^+$ — jump across a face (normal points from $-$ to $+$)
- $\epsilon = -1$ — SIPG sign (makes the bilinear form symmetric)
- $\alpha$ — IP penalty parameter (formula in Section 3.8)
- $\boldsymbol{\delta}$ — prescribed fault slip (known data from ODE)
- $\mathbf{u}_D$ — prescribed Dirichlet displacement (far-field plate loading)

The complete DG system $K\mathbf{u} = \mathbf{b}$ is built from the
following terms. Each term is labeled and will be traced from weak form
through discretization to code in the sections that follow.

**Left-hand side (→ stiffness matrix $K$):**

> **[Term V]** $\quad \displaystyle\sum_K \int_K \boldsymbol{\sigma}(\mathbf{u}) : \boldsymbol{\varepsilon}(\mathbf{w}) \, dV$
> — volume integral (element stiffness)

> **[Term C]** $\quad \displaystyle -\sum_F \int_F \{\boldsymbol{\sigma}(\mathbf{u}) \cdot \mathbf{n}\} \cdot [\![ \mathbf{w} ]\!] \, dS$
> — consistency (average traction of $\mathbf{u}$ tested against jump of $\mathbf{w}$)

> **[Term S]** $\quad \displaystyle \epsilon \sum_F \int_F \{\boldsymbol{\sigma}(\mathbf{w}) \cdot \mathbf{n}\} \cdot [\![ \mathbf{u} ]\!] \, dS$
> — symmetry (mirror of Term C; makes $K$ symmetric when $\epsilon = -1$)

> **[Term P]** $\quad \displaystyle \sum_F \int_F \alpha \, [\![ \mathbf{u} ]\!] \cdot [\![ \mathbf{w} ]\!] \, dS$
> — penalty (stabilization; penalizes the displacement jump)

**Right-hand side (→ load vector $\mathbf{b}$):**

On **fault faces**, the jump is prescribed: $[\![ \mathbf{u} ]\!] = \boldsymbol{\delta}$.
Substituting this known value into Terms S and P moves them to the RHS:

> **[Term F-S]** $\quad \displaystyle \epsilon \int_F \{\boldsymbol{\sigma}(\mathbf{w}) \cdot \mathbf{n}\} \cdot \boldsymbol{\delta} \, dS$
> — slip RHS from Term S (traction of test $\times$ known slip)

> **[Term F-P]** $\quad \displaystyle \int_F \alpha \, \boldsymbol{\delta} \cdot [\![ \mathbf{w} ]\!] \, dS$
> — slip RHS from Term P (penalty $\times$ known slip)

On **Dirichlet boundary faces**, $\mathbf{u} = \mathbf{u}_D$ is prescribed.
Same substitution, but with full (not halved) coefficients since boundary
faces have only one adjacent element:

> **[Term D]** $\quad \displaystyle \epsilon \int_F \boldsymbol{\sigma}(\mathbf{w}) \cdot \mathbf{n} \cdot \mathbf{u}_D \, dS + \int_F \alpha \, \mathbf{u}_D \cdot \mathbf{w} \, dS$
> — Dirichlet RHS (combined symmetry + penalty with known $\mathbf{u}_D$)

After solving $K\mathbf{u} = \mathbf{b}$, the traction is recovered:

> **[Term T]** $\quad T_p = \frac{1}{2}(\sigma^{(1)}_{pj} + \sigma^{(2)}_{pj})\hat{n}_j - \alpha(u^{(1)}_p - u^{(2)}_p - \delta_p)$
> — traction recovery (post-processing, not a weak-form term)

The sections below trace each term in order. Each section repeats the
full weak form and marks the current term with **[** $\leftarrow$ **HERE]**
so you always know where you are.

Section 3.4 first explains the shared machinery (basis functions,
quadrature, the adjugate trick, the traction operator) that converts
any of these integrals into code. Sections 3.5–3.14 then apply this
machinery term by term.

### 3.4 How Any Integral Becomes Code (Shared Machinery)

This section explains the common steps that turn every weak-form integral
into matrix/vector entries in the code. Understanding this once makes
every subsequent term derivation transparent.

#### Step A: Basis Function Expansion

In FEM, we approximate the continuous displacement field $\mathbf{u}(\mathbf{x})$
as a weighted sum of known shape functions (basis functions). On each
element $K$, the DG space provides scalar basis functions
$\phi_0(\mathbf{x}), \phi_1(\mathbf{x}), \ldots, \phi_{N-1}(\mathbf{x})$
that are polynomials of degree $p$ and are nonzero only inside $K$.

For a vector field in 3D, we represent each component separately:

$$\mathbf{u}(\mathbf{x}) = \sum_{l=0}^{N-1} \sum_{j=1}^{3} U_{l,j} \, \phi_l(\mathbf{x}) \, \mathbf{e}_j$$

where $U_{l,j}$ are the unknown coefficients (DOFs) and $\mathbf{e}_j$ is the
unit vector in direction $j$. The test function $\mathbf{w}$ uses the same
basis: we set $\mathbf{w} = \phi_k(\mathbf{x}) \, \mathbf{e}_i$ and require
the equation to hold for every choice of $k$ and $i$.

In code, the FE space is created at `elasticity_operator.hpp:373-379`:
```cpp
fec_ = std::make_unique<DG_FECollection>(order_, 3, BasisType::GaussLobatto);
fes_ = std::make_unique<FESpaceType>(&mesh_, fec_.get(), 3, Ordering::byNODES);
```
`DG_FECollection` creates discontinuous polynomial bases. The `3` means
3 vector components. `Ordering::byNODES` stores DOFs as
$[u_x^0, u_x^1, \ldots, u_y^0, u_y^1, \ldots, u_z^0, u_z^1, \ldots]$.

#### Step B: From Integral to Matrix Entry

After substituting the basis expansion, every integral of the form
$\int (\text{something involving } \mathbf{u}) \cdot (\text{something involving } \mathbf{w}) \, dS$
becomes a double sum over DOFs. The coefficient multiplying $U_{l,j}$
when tested with $\phi_k \mathbf{e}_i$ is the matrix entry $K_{(k,i),(l,j)}$.

For example, the volume term:

$$\int_K \boldsymbol{\sigma}(\mathbf{u}) : \boldsymbol{\varepsilon}(\mathbf{w}) \, dV = \sum_{l,j} U_{l,j} \cdot \Bigl[\int_K \boldsymbol{\sigma}(\phi_l \mathbf{e}_j) : \boldsymbol{\varepsilon}(\phi_k \mathbf{e}_i) \, dV\Bigr]$$

The bracketed integral depends only on the basis functions and material
properties — not on the unknown $U_{l,j}$. It is the matrix entry
$K^\text{vol}_{(k,i),(l,j)}$.

If the term involves a known function (like the prescribed slip
$\boldsymbol{\delta}$) instead of the unknown $\mathbf{u}$, the integral
becomes a vector entry $b_{k,i}$ on the right-hand side rather than a
matrix entry.

#### Step C: Numerical Quadrature

We cannot evaluate these integrals analytically in general. Instead, we
approximate each integral as a weighted sum over quadrature points:

$$\int_F f(\mathbf{x}) \, dS \approx \sum_{q=0}^{N_q-1} w_q \, f(\mathbf{x}_q)$$

where $w_q$ are quadrature weights and $\mathbf{x}_q$ are quadrature
point locations. The code uses quadrature of order $2p+1$ for face
integrals (`:59-62` of the combined integrator), which is exact for
the product of two order-$p$ shape function gradients:

```cpp
// dg_elasticity_ip_combined_integrator.hpp:59-62
const int order = 2 * std::max(el1.GetOrder(),
                                ndof2 ? el2.GetOrder() : 0) + 1;
const IntegrationRule &ir = IntRules.Get(Trans.GetGeometryType(), order);
```

At each quadrature point, the code evaluates the shape functions
$\phi_k(q)$ (`CalcShape`) and their gradients $\nabla\phi_k(q)$
(`CalcDShape`):

```cpp
// dg_elasticity_ip_combined_integrator.hpp:76-79
el1.CalcShape(eip1, shape1);          // shape1[k] = φ_k(x_q)
el1.CalcDShape(eip1, dshape1_ref);    // dshape1_ref[k,d] = ∂φ_k/∂ξ_d (reference coords)
CalcAdjugate(Trans.Elem1->Jacobian(), adjJ);
Mult(dshape1_ref, adjJ, dshape1_adj); // dshape1_adj[k,d] = |J| · ∂φ_k/∂x_d (physical)
```

#### Step D: Reference-to-Physical Mapping (The Adjugate Trick)

The mesh elements are defined in a reference coordinate system
$\hat{\mathbf{x}} = (\xi_1, \xi_2, \xi_3)$. The Jacobian matrix
$J_{ij} = \partial x_i / \partial \xi_j$ maps reference to physical
coordinates. Shape function gradients are naturally computed in
reference coordinates ($\partial\phi/\partial\xi$), but the physics
needs physical gradients ($\partial\phi/\partial x$).

The relationship is:

$$\frac{\partial \phi}{\partial x} = \frac{\partial \phi}{\partial \xi} \cdot J^{-1}$$

Computing $J^{-1}$ is expensive, so the code uses the **adjugate**
(cofactor matrix) instead: $\text{adj}(J) = |J| \cdot J^{-1}$.
This gives:

$$\text{dshape\_adj}_{k,d} = \sum_m \frac{\partial \phi_k}{\partial \xi_m} \cdot \text{adj}(J)_{m,d} = |J| \cdot \frac{\partial \phi_k}{\partial x_d}$$

So `dshape_adj` is the physical gradient scaled by $|J|$. Whenever the
code uses `dshape_adj`, it divides by `detJ` later to recover the true
physical gradient. This is why you see `/ detJ_trial` and `/ detJ_test`
in the face integrator.

#### Step E: Face Geometry — Normal Vector and Area

On each face, the code computes the outward normal vector via:

```cpp
// dg_elasticity_ip_combined_integrator.hpp:81-82
CalcOrtho(Trans.Jacobian(), nor);   // nor = unnormalized face normal
real_t nl_q = nor.Norml2();         // nl_q = |nor| = face area element
```

`CalcOrtho` computes the cross product of the face Jacobian columns,
giving an unnormalized normal whose magnitude equals the face area
element at that quadrature point. The unit normal is
$\hat{\mathbf{n}} = \mathbf{n}/|\mathbf{n}|$.

The face integral measure $dS$ becomes $|\mathbf{n}_q| \cdot w_q$ in
the quadrature sum. Some terms use the unnormalized normal directly
(which absorbs the area element), while others use the unit normal
and multiply by $|\mathbf{n}_q|$ separately.

#### Step F: The Traction Operator $T$

The expression $\boldsymbol{\sigma}(\mathbf{v}) \cdot \mathbf{n}$ appears
in every face term. For an isotropic material, its $p$-th component is:

$$(\boldsymbol{\sigma}(\mathbf{v}) \cdot \mathbf{n})_p = \lambda (\nabla \cdot \mathbf{v}) n_p + \mu \left(\frac{\partial v_p}{\partial x_j} n_j + \frac{\partial v_j}{\partial x_p} n_j\right)$$

When $\mathbf{v} = \phi_l \, \mathbf{e}_u$ (a single basis function in
direction $u$), only one component of $\nabla\mathbf{v}$ is nonzero:
$\partial v_u / \partial x_d = \partial\phi_l/\partial x_d$, and all
other $\partial v_j/\partial x_d = 0$. Substituting:

$$T(\phi_l \mathbf{e}_u, \mathbf{n})_p = \lambda \frac{\partial \phi_l}{\partial x_u} n_p + \mu \left(\delta_{up} \sum_d \frac{\partial \phi_l}{\partial x_d} n_d + \frac{\partial \phi_l}{\partial x_p} n_u\right)$$

In words: the first term is the volumetric stress contribution ($\lambda$
times divergence times normal), and the two $\mu$ terms are the shear
stress contributions. This traction operator is the building block for
Terms C, S, and the slip/Dirichlet RHS.

In the code, using `dshape_adj` (which includes the $|J|$ factor):

```cpp
// dg_elasticity_ip_combined_integrator.hpp:852-855
real_t T_trial_lup =
   lam_trial * dshape_adj_trial(l, u) * nor(p)              // λ |J| (∂φ_l/∂x_u) n_p
   + mu_trial * ((u == p ? 1.0 : 0.0) * grad_dot_n_trial(l) // μ |J| δ_{up} (∇φ_l · n)
                  + dshape_adj_trial(l, p) * nor(u));         // μ |J| (∂φ_l/∂x_p) n_u
```

Note: `dshape_adj` is already multiplied by $|J|$, and `nor` is the
unnormalized normal (which includes the face area element). The
division by `detJ` that follows (`:857`) cancels the $|J|$ from
`dshape_adj`, converting back to the physical gradient. The face area
element from `nor` combines with the quadrature weight $w_q$ to
produce the $dS$ measure.

#### Step G: Two-Element Face Assembly

Each interior face is shared by two elements. The jump
$[\![\mathbf{w}]\!] = \mathbf{w}^- - \mathbf{w}^+$ means that test
functions from element 1 contribute with one sign and element 2 with
the opposite. Similarly, the average
$\{\boldsymbol{\sigma}\} = \tfrac{1}{2}(\boldsymbol{\sigma}^- + \boldsymbol{\sigma}^+)$
takes half from each side.

This produces a $2 \times 2$ block structure: the face matrix has four
blocks corresponding to (test from elem $a$, trial from elem $b$) for
$a, b \in \{1, 2\}$. The coefficients $c_0, c_1, c_2$ that differ per
block encode exactly these $\pm\tfrac{1}{2}$ and $\pm 1$ factors. The
code computes all four blocks in `AssembleFaceMatrix()`:

```cpp
// dg_elasticity_ip_combined_integrator.hpp:114-166
// Block (0,0): test=elem1, trial=elem1 → same-side signs
AssembleFaceBlock(..., -0.5, 0.5*epsilon_, penalty, elmat);    // :114-125
// Block (0,1): test=elem1, trial=elem2 → cross signs
AssembleFaceBlock(..., -0.5, -0.5*epsilon_, -penalty, elmat);  // :129-140
// Block (1,0): test=elem2, trial=elem1 → cross signs
AssembleFaceBlock(..., 0.5, 0.5*epsilon_, -penalty, elmat);    // :142-153
// Block (1,1): test=elem2, trial=elem2 → same-side signs
AssembleFaceBlock(..., 0.5, -0.5*epsilon_, penalty, elmat);    // :155-166
```

The sign pattern for the penalty coefficient $[+, -, -, +]$ comes directly
from expanding $(w^- - w^+)(u^- - u^+) = w^-u^- - w^-u^+ - w^+u^- + w^+u^+$.

Now we can trace each term. The derivation from weak form to code
follows the chain: **write the integral → insert basis expansion
(Step B) → replace $\int$ with $\sum_q w_q$ (Step C) → express
gradients via adjugate (Step D) → evaluate the traction operator
(Step F) → assemble into the four blocks (Step G)**.

### 3.5 Term V — Volume

**Where we are in the full weak form:**

> **[Term V]** $\leftarrow$ HERE $\quad \sum_K \int_K \boldsymbol{\sigma}(\mathbf{u}) : \boldsymbol{\varepsilon}(\mathbf{w}) \, dV$ — volume
>
> [Term C] $\quad -\sum_F \int_F \{\boldsymbol{\sigma}(\mathbf{u}) \cdot \mathbf{n}\} \cdot [\![ \mathbf{w} ]\!] \, dS$ — consistency
>
> [Term S] $\quad \epsilon \sum_F \int_F \{\boldsymbol{\sigma}(\mathbf{w}) \cdot \mathbf{n}\} \cdot [\![ \mathbf{u} ]\!] \, dS$ — symmetry
>
> [Term P] $\quad \sum_F \int_F \alpha \, [\![ \mathbf{u} ]\!] \cdot [\![ \mathbf{w} ]\!] \, dS$ — penalty

**Weak form.** This is the volume integral that survives from the
integration by parts — the stress of $\mathbf{u}$ contracted with the
strain of $\mathbf{w}$ over each element:

**Discretization.** Insert the basis expansion (Step B): set
$\mathbf{u} = \sum_l U_{l,j} \phi_l \mathbf{e}_j$ and
$\mathbf{w} = \phi_k \mathbf{e}_i$. The stress tensor
$\boldsymbol{\sigma}(\phi_l \mathbf{e}_j)$ has components
$\sigma_{pq} = \lambda \delta_{pq} \partial\phi_l/\partial x_j + \mu(\delta_{pj}\partial\phi_l/\partial x_q + \delta_{qj}\partial\phi_l/\partial x_p)$.
Contracting $\boldsymbol{\sigma}:\boldsymbol{\varepsilon}$ and applying
quadrature (Step C), each element $K$ contributes:

$$K^\text{vol}_{(k,i),(l,j)} = \sum_q w_q \left[\lambda \frac{\partial \phi_k}{\partial x_i} \frac{\partial \phi_l}{\partial x_j} + \mu \left(\sum_m \frac{\partial \phi_k}{\partial x_m} \frac{\partial \phi_l}{\partial x_m} \delta_{ij} + \frac{\partial \phi_k}{\partial x_j} \frac{\partial \phi_l}{\partial x_i}\right)\right] |J_q|$$

The gradients $\partial\phi/\partial x$ are computed via the adjugate
trick (Step D). The integral is over the element volume, so the measure
is $|J_q| \cdot w_q$.

**Code.** This is handled entirely by MFEM's built-in `ElasticityIntegrator` —
no custom code. It is registered into the bilinear form at:

```cpp
// elasticity_operator.hpp:978-980
cached_a_->AddDomainIntegrator(
   new ElasticityIntegrator(lambda_coeff_, mu_coeff_));
```

Because DG basis functions have support only on one element, this
produces the block-diagonal part of $K$ (no inter-element coupling).
All off-diagonal coupling comes from the face terms below.

### 3.6 Term C — Consistency (Interior Faces)

**Where we are in the full weak form:**

> [Term V] $\quad \sum_K \int_K \boldsymbol{\sigma}(\mathbf{u}) : \boldsymbol{\varepsilon}(\mathbf{w}) \, dV$ — volume
>
> **[Term C]** $\leftarrow$ HERE $\quad -\sum_F \int_F \{\boldsymbol{\sigma}(\mathbf{u}) \cdot \mathbf{n}\} \cdot [\![ \mathbf{w} ]\!] \, dS$ — consistency
>
> [Term S] $\quad \epsilon \sum_F \int_F \{\boldsymbol{\sigma}(\mathbf{w}) \cdot \mathbf{n}\} \cdot [\![ \mathbf{u} ]\!] \, dS$ — symmetry
>
> [Term P] $\quad \sum_F \int_F \alpha \, [\![ \mathbf{u} ]\!] \cdot [\![ \mathbf{w} ]\!] \, dS$ — penalty

**Weak form.** On each interior face $F$ between elements $K^-$ and $K^+$,
this term computes the average traction of the trial function $\mathbf{u}$
and dots it with the jump of the test function $\mathbf{w}$. It enforces
traction continuity across elements — if $\mathbf{u}$ were the exact
solution, $\boldsymbol{\sigma}\cdot\mathbf{n}$ would be continuous and
this term would vanish.

**Discretization.** Insert the basis expansion (Step B). The average
$\{\boldsymbol{\sigma}(\mathbf{u})\cdot\mathbf{n}\}$ takes $\tfrac{1}{2}$
from each element's contribution, producing the $\pm 0.5$ in coefficient
$c_0$. The jump $[\![\mathbf{w}]\!] = \mathbf{w}^- - \mathbf{w}^+$
means test functions from elem1 enter with $+1$ and elem2 with $-1$.

Applying the traction operator (Step F) to the trial basis function
$\phi_l \mathbf{e}_u$, and quadrature (Step C), the contribution to
the face matrix is:

$$K^\text{C}_{(a,k,i),(b,l,u)} \mathrel{+}= c_0 \cdot \phi_k^{(a)}(q) \cdot T(\phi_l \mathbf{e}_u, \mathbf{n}_q)_i \cdot w_q / |J_\text{trial}|$$

The $\phi_k^{(a)}$ comes from the test function $\mathbf{w}$
(its value on the face). The traction operator $T$ encodes the stress
of the trial function. The $/ |J_\text{trial}|$ cancels the $|J|$
inside `dshape_adj` (Step D), recovering the physical gradient.

**Code.** Inside `AssembleFaceBlock()`, the consistency contribution
for one (test, trial) block:

$$T(\phi_l \mathbf{e}_u, \mathbf{n})_p = \lambda \frac{\partial \phi_l}{\partial x_u} n_p + \mu \left(\delta_{up} (\nabla \phi_l \cdot \mathbf{n}) + \frac{\partial \phi_l}{\partial x_p} n_u\right)$$

### 3.7 Term S — Symmetry (Interior Faces)

**Where we are in the full weak form:**

> [Term V] $\quad \sum_K \int_K \boldsymbol{\sigma}(\mathbf{u}) : \boldsymbol{\varepsilon}(\mathbf{w}) \, dV$ — volume
>
> [Term C] $\quad -\sum_F \int_F \{\boldsymbol{\sigma}(\mathbf{u}) \cdot \mathbf{n}\} \cdot [\![ \mathbf{w} ]\!] \, dS$ — consistency
>
> **[Term S]** $\leftarrow$ HERE $\quad \epsilon \sum_F \int_F \{\boldsymbol{\sigma}(\mathbf{w}) \cdot \mathbf{n}\} \cdot [\![ \mathbf{u} ]\!] \, dS$ — symmetry
>
> [Term P] $\quad \sum_F \int_F \alpha \, [\![ \mathbf{u} ]\!] \cdot [\![ \mathbf{w} ]\!] \, dS$ — penalty

**Weak form.** Compare with Term C: there, the traction operator acted
on the trial function $\mathbf{u}$ and the jump was of the test $\mathbf{w}$.
Here the roles are swapped — the traction operator acts on the test
$\mathbf{w}$ and the jump is of the trial $\mathbf{u}$.

With $\epsilon = -1$ (SIPG), this term makes the bilinear form symmetric:
combined with Term C, we get $-\int\{T_u\}\cdot[\![w]\!] - \int\{T_w\}\cdot[\![u]\!]$,
which is symmetric in $\mathbf{u}$ and $\mathbf{w}$. Symmetry is
required for the stiffness matrix to be SPD, enabling CG as the solver.

**Discretization.** Following the same chain as Term C (Steps B, C, F),
but now the traction operator $T$ (from Step F) is applied to the
*test* basis function $\phi_k \mathbf{e}_i$ instead of the trial, and
the trial's shape function $\phi_l^{(b)}$ provides the scalar value:

$$K^\text{S}_{(a,k,i),(b,l,u)} \mathrel{+}= c_1 \cdot \phi_l^{(b)}(q) \cdot T(\phi_k \mathbf{e}_i, \mathbf{n}_q)_u \cdot w_q / |J_\text{test}|$$

The $/ |J_\text{test}|$ cancels the $|J|$ in `dshape_adj_test`
(Step D), just as $/ |J_\text{trial}|$ did in Term C.

**Code location — `AssembleFaceBlock()`:**

### 3.8 Term P — Penalty (Interior Faces)

**Where we are in the full weak form:**

> [Term V] $\quad \sum_K \int_K \boldsymbol{\sigma}(\mathbf{u}) : \boldsymbol{\varepsilon}(\mathbf{w}) \, dV$ — volume
>
> [Term C] $\quad -\sum_F \int_F \{\boldsymbol{\sigma}(\mathbf{u}) \cdot \mathbf{n}\} \cdot [\![ \mathbf{w} ]\!] \, dS$ — consistency
>
> [Term S] $\quad \epsilon \sum_F \int_F \{\boldsymbol{\sigma}(\mathbf{w}) \cdot \mathbf{n}\} \cdot [\![ \mathbf{u} ]\!] \, dS$ — symmetry
>
> **[Term P]** $\leftarrow$ HERE $\quad \sum_F \int_F \alpha \, [\![ \mathbf{u} ]\!] \cdot [\![ \mathbf{w} ]\!] \, dS$ — penalty

**Weak form.** The stabilization term that penalizes the displacement jump.
Without sufficient penalty, the SIPG method is unstable — $K$ can have
zero or negative eigenvalues and the linear solve fails.

**Discretization.** This is the simplest face term. Unlike Terms C and S,
no gradients or traction operators appear — only shape function values.
Insert the basis expansion (Step B): $[\![\mathbf{u}]\!]_i = \sum_l U_{l,i}(\phi_l^- - \phi_l^+)$,
and similarly for $[\![\mathbf{w}]\!]_i = (\phi_k^- - \phi_k^+)$.
The integral becomes a face mass matrix scaled by $\alpha$, acting
component-wise (the $\delta_{iu}$ means displacement components don't
cross-couple):

$$K^\text{P}_{(a,k,i),(b,l,u)} \mathrel{+}= c_2 \cdot \phi_k^{(a)} \cdot \phi_l^{(b)} \cdot \delta_{iu} \cdot |\mathbf{n}_q| \cdot w_q$$

**Code location — `AssembleFaceBlock()`:**

**Penalty parameter $\alpha$ — `ComputePenalty()`:**

In formulas:

$$c_N = \frac{p(p + d - 1)}{d}, \qquad r = \frac{(d\lambda + 2\mu)^2}{2\mu}$$

$$\alpha_\text{side} = (d + 1) \cdot c_N \cdot \frac{d \, |\mathbf{n}|}{|J|} \cdot r$$

$$\alpha = \gamma \cdot \frac{\alpha_\text{side1} + \alpha_\text{side2}}{4} \quad (\text{interior}), \qquad \alpha = \gamma \cdot \alpha_\text{side1} \quad (\text{boundary})$$

### 3.10 Term F-S — Fault Slip RHS (Symmetry Data)

**Where we are — RHS terms (fault faces with known slip $\boldsymbol{\delta}$):**

> **[Term F-S]** $\leftarrow$ HERE $\quad \epsilon \int_F \{\boldsymbol{\sigma}(\mathbf{w}) \cdot \mathbf{n}\} \cdot \boldsymbol{\delta} \, dS$ — from Term S
>
> [Term F-P] $\quad \int_F \alpha \, \boldsymbol{\delta} \cdot [\![ \mathbf{w} ]\!] \, dS$ — from Term P
>
> [Term D] $\quad \epsilon \int_F \boldsymbol{\sigma}(\mathbf{w}) \cdot \mathbf{n} \cdot \mathbf{u}_D \, dS + \int_F \alpha \, \mathbf{u}_D \cdot \mathbf{w} \, dS$ — Dirichlet

**Weak form.** On a fault face the displacement jump is not unknown —
it equals the prescribed slip: $[\![\mathbf{u}]\!] = \boldsymbol{\delta}$.
Look back at Term S: $\epsilon \int_F \{\boldsymbol{\sigma}(\mathbf{w})\cdot\mathbf{n}\}\cdot[\![\mathbf{u}]\!]\,dS$.
Replacing $[\![\mathbf{u}]\!]$ with the known $\boldsymbol{\delta}$ turns this
from a bilinear form (which would go into $K$) into a linear form (which
goes into the RHS vector $\mathbf{b}$):

$$\epsilon \int_F \{\boldsymbol{\sigma}(\mathbf{w}) \cdot \mathbf{n}\} \cdot \boldsymbol{\delta} \, dS$$

**Discretization.** The derivation is identical to Term S (Section 3.7),
except the trial function $\phi_l \mathbf{e}_u$ is replaced by the known
slip $\boldsymbol{\delta}(q)$ evaluated at the quadrature point. The
traction operator (Step F) still acts on the test function $\phi_k$:

$$b^\text{F-S}_{k,i} \mathrel{+}= \frac{\epsilon}{2} \cdot T(\phi_k \mathbf{e}_i, \mathbf{n})_u \cdot \delta_u(q) \cdot w_q / |J|$$

Here $T(\phi_k \mathbf{e}_i, \mathbf{n})_u$ is the traction of the test
function (same operator from Step F), and $\delta_u(q)$ is the known
slip evaluated at quadrature point $q$.

The $\epsilon/2$ comes from the same $c_1$ coefficient as Term S (same-side),
but now it's the same for both elements because both see the full
prescribed slip (not a half-average).

### 3.12 Term D — Dirichlet RHS

**Where we are — RHS terms (Dirichlet boundary faces):**

**Weak form.** On Dirichlet boundary faces the solution is prescribed:

### 3.13 Traction Recovery (Post-solve)

After solving $K\mathbf{u} = \mathbf{b}$, the traction on each fault face is recovered.
This is NOT a new weak-form term but a post-processing step that evaluates
the same DG flux formula used in the bilinear form.

**Formula.** At each quadrature point $q$ on a fault face, the traction has
two parts — the stress average and the penalty correction:

$$T_p(q) = \frac{1}{2}\sum_j \bigl(\sigma^{(1)}_{pj} + \sigma^{(2)}_{pj}\bigr) \hat{n}_j \;-\; \alpha \bigl(u^{(1)}_p - u^{(2)}_p - \delta_p\bigr)$$

The first part (stress average $\{\boldsymbol{\sigma}\}\cdot\hat{\mathbf{n}}$)
comes from Term C's traction operator. The second part (penalty correction
$-\alpha \cdot \text{jump residual}$) comes from Term P.

**Stress average** (`:500-516`):

## 4. Assembly Pipeline: $K$, $\mathbf{b}$, and the Linear Solve

### 4.1 Stiffness Matrix $K$

$K$ is assembled once in `AssembleStiffness()` (`elasticity_operator.hpp:962-1023`)
and cached for all subsequent Solve calls. The stiffness matrix is SPD for
SIPG ($\epsilon = -1$) with sufficient penalty.

$$K = K_\text{vol} + K_\text{interior faces} + K_\text{boundary faces}$$

**Assembly call graph with line numbers:**
```
AssembleStiffness()                                elasticity_operator.hpp:962
├── ExchangeFaceNbrData()                          :968-973   (MPI only)
├── AddDomainIntegrator(ElasticityIntegrator)       :978-980   Term V
├── AddInteriorFaceIntegrator(IPCombined)           :1009-1011 Terms C+S+P
├── AddBdrFaceIntegrator(IPCombined, dirichlet)     :1015-1018 Terms C+S+P (boundary)
├── cached_a_->Assemble()                           :1022
├── cached_a_->Finalize()                           :1023
└── ParallelAssemble(cached_Ah_)                    :1030      → HypreParMatrix
```

**Key point:** Fault faces are interior faces in MFEM and contribute to $K$
just like any other interior face. The fault slip enters only through
the RHS vector $\mathbf{b}$.

### 4.2 RHS Vector $\mathbf{b}$

The RHS is rebuilt every Solve call (`elasticity_operator.hpp:2780-2827`):

$$\mathbf{b} = \mathbf{b}_\text{slip} + \mathbf{b}_\text{Dirichlet}$$

#### 5.2.1 Slip RHS ($\mathbf{b}_\text{slip}$)

Assembled in `AssembleSlipContributionIP()` (`elasticity_operator.hpp:1163-1266`).

For each fault face:
1. **Transform slip from fault-local to global:** The 2-component
   (dip, strike) slip is embedded into 3D using `FaultBasis::EmbedSlipQP()`,
   producing $\boldsymbol{\delta}(q) \in \mathbb{R}^3$ at each quad point.

2. **Sign correction:** The slip sign depends on which side of the fault the
   mesh normal points. $\text{sign} = \text{basis.sign\_flipped} \;?\; +1 : -1$.

3. **Assemble RHS via combined integrator:**
   ```cpp
   slip_integrator.AssembleSlipFaceRHS(
      *fe1, *fe2, *FTr, delta_u_quad, elvec1, elvec2);
   ```

The `AssembleSlipFaceRHS` method (`dg_elasticity_ip_combined_integrator.hpp:210-340`)
computes two contributions per element:

$$b_k^i \mathrel{+}= c_1 \sum_u T(\phi_k \mathbf{e}_i, \mathbf{n})_u \, \delta_u \, \frac{w_q}{|J|} + c_2 \, \phi_k \, \delta_i \, w_q$$

where $c_1 = \epsilon/2$ and $c_2 = +\alpha$ for element 1, $-\alpha$ for element 2.

**Consistency guarantee:** The slip RHS uses the SAME integrator class
(`DGElasticityIPCombinedIntegrator`) and the SAME penalty formula as the
stiffness matrix $K$. This $K$-$\mathbf{b}$ consistency is critical for correctness.

#### 5.2.2 Dirichlet RHS ($\mathbf{b}_\text{Dirichlet}$)

Assembled in `AssembleDirichletLoading()` (`elasticity_operator.hpp:1865`).

The Dirichlet value is $\mathbf{u}_D = \left(\text{sgn}(Y) \cdot V_p \, t / 2, \; 0, \; 0\right)$, applied on
boundary faces with attribute 5 (far-field walls). The same symmetry +
penalty pattern is used, with full (not halved) coefficients since boundary
faces have only one adjacent element.

### 5.3 Linear Solve

**System:** $K \mathbf{u} = \mathbf{b}$, where $K$ is a sparse SPD matrix (for SIPG with DG).

**Solver options** (selected via `SolverType` enum, `elasticity_operator.hpp:36`):

| Solver | Code path | Use case |
|--------|-----------|----------|
| `MUMPS_BLR` (default) | `elasticity_operator.hpp:1041-1049` | Direct solver with BLR compression. Robust, moderate memory. |
| `MUMPS` | `elasticity_operator.hpp:1033-1040` | Direct solver, full factorization |
| `CG_AMG` | `elasticity_operator.hpp:1131-1144` | CG + BoomerAMG. Iterative, low memory. |
| `GMRES_AMG` | `elasticity_operator.hpp:1102-1128` | For DG at high $p$ where AMG is non-SPD |
| `GMRES_BlockILU` | `elasticity_operator.hpp:1084-1100` | Block-ILU preconditioner (DG-natural) |

The solve happens in `Solve()` at `elasticity_operator.hpp:2772`:

## 6. Fault Interface: Slip to Traction

### 6.1 Fault Face Detection

Fault faces are identified by mesh boundary element attributes.
Tandem's Gmsh mesh tags faces with Physical Surface attributes:
- **Tag 1** = Natural (top + bottom)
- **Tag 3** = Fault ($Y = 0$ interior)
- **Tag 5** = Dirichlet (far-field)

`BuildFaultTaggedFaces()` (`elasticity_operator.hpp:421-498`) maps each
attr-3 boundary element to its face index using `GetBdrElementFaceIndex()`.
A coordinate-based fallback exists for meshes without tags.

### 6.2 Fault Coordinate Frame

Each fault face gets a local coordinate frame: (dip, strike, normal).

**Algorithm** (matching Tandem `Curvilinear::facetBasis`, in `fault_basis.hpp:44-100`):
1. Get raw face normal from `CalcOrtho(face_jacobian, n_raw)`

2. Orient: if $\mathbf{n}_\text{raw} \cdot \mathbf{n}_\text{ref} < 0$, flip. $\mathbf{n}_\text{ref} = (0, -1, 0)$.

3. Normalize: $\hat{\mathbf{n}} = \mathbf{n}_\text{raw} / |\mathbf{n}_\text{raw}|$

4. $\hat{\mathbf{s}} = \text{normalize}(\mathbf{e}_\text{up} \times \hat{\mathbf{n}})$, where $\mathbf{e}_\text{up} = (0, 0, 1)$

5. $\hat{\mathbf{d}} = \hat{\mathbf{s}} \times \hat{\mathbf{n}}$

6. $\text{tangent}_1 = \hat{\mathbf{d}}$, $\text{tangent}_2 = \hat{\mathbf{s}}$

For higher-order elements, per-quadrature-point tangent frames are computed
(`ComputeQPBasis`, `fault_basis.hpp:112-138`) since the normal varies
across the face for curved meshes.

### 6.3 Traction Recovery

After solving $K \mathbf{u} = \mathbf{b}$, the traction on each fault face is recovered in
`ComputeTractionImpl()` (`elasticity_operator.hpp:3176`).

**IP method** (primary path for BP5):

The traction at each quad point has two parts:

$$\mathbf{T}(q) = \mathbf{T}_\text{stress}(q) + \mathbf{T}_\text{correction}(q)$$

where:

$$T_{\text{stress},\,p}(q) = \frac{1}{2} \sum_j \left(\sigma^{(1)}_{pj} + \sigma^{(2)}_{pj}\right) \hat{n}_j$$

$$T_{\text{correction},\,p}(q) = -\alpha \left(u^{(1)}_p(q) - u^{(2)}_p(q) - \delta_p(q)\right)$$

This is computed in `ComputeTractionAtQuadPoints()` (`dg_elasticity_ip_combined_integrator.hpp:421-541`):

```cpp
// Stress average: {sigma} = 0.5*(sigma_0 + sigma_1)
for (int p = 0; p < dim_; p++) {
   real_t T_p = 0.0;
   for (int j = 0; j < dim_; j++) {
      real_t eps1 = 0.5*(grad1(p,j) + grad1(j,p));
      real_t eps2 = 0.5*(grad2(p,j) + grad2(j,p));
      real_t sig1 = (p==j ? lam1t*tr1 : 0.0) + 2.0*mu1t*eps1;
      real_t sig2 = (p==j ? lam2t*tr2 : 0.0) + 2.0*mu2t*eps2;
      T_p += 0.5 * (sig1 + sig2) * n_hat(j);
   }
   traction_q(p * nq + q) = T_p;
}
// Penalty correction: -alpha * (u_jump - slip)
traction_q(c * nq + q) += (-penalty) * (u1q - u2q - f_q);
```

**Projection to fault DOFs:**

The 3D traction at quad points is projected to 2-component (dip, strike)
values at fault DOFs using `ProjectTractionToFaultDOFs()`:

$$\tau_{\text{dof}}^{(c)}(k) = \sum_q \left(\mathbf{T}(q) \cdot \hat{\mathbf{t}}_c(q)\right) \phi_k(q) \, |\mathbf{n}(q)| \, w_q$$

where $\hat{\mathbf{t}}_c$ is the dip or strike tangent vector, and $|\mathbf{n}(q)|$
is the face-area Jacobian at each quad point.

### 6.4 Normal Traction ($\sigma_n$ Feedback)

For the elastic normal stress feedback (v51/v55), the normal component of
traction is also extracted:

$$T_n(q) = \sum_p T_p(q) \, \hat{n}_p(q)$$

This is stored in `normal_traction_` and passed to `ComputeRHS()` to modify
the effective normal stress: $\sigma_n^\text{eff} = \sigma_n + T_n$ (matching Tandem's
`DieterichRuinaBase.h:87`).

## 7. Rate-and-State Friction and State Evolution

### 7.1 Regularized Dieterich-Ruina Friction

**File:** `friction/dieterich_ruina.hpp`

The friction coefficient in $\psi$-space (regularized form):

$$f(V, \psi) = a \, \text{arcsinh}\!\left(\frac{V}{2V_0} \exp\!\left(\frac{\psi}{a}\right)\right)$$

where $\psi = f_0 + b \ln(V_0 \, \theta / D_c)$ is the logarithmic state variable.

This is evaluated in `FrictionCoefficientPsi()` (`dieterich_ruina.hpp:~316`).

### 7.2 Stress Balance: Solving for $V$

The friction law defines the stress balance:

$$|\boldsymbol{\tau}| = \sigma_n \, f(|V|, \psi) + \eta \, |V|$$

Given $\boldsymbol{\tau}$ (from domain solve + pre-stress) and $\psi$ (from state), we solve
for $|V|$ using Brent's method (root bracketing):

$$F(V) = \sigma_n \, a \, \text{arcsinh}\!\left(\frac{V}{2V_0} \exp\!\left(\frac{\psi}{a}\right)\right) + \eta V - |\boldsymbol{\tau}| = 0$$

This is monotonically increasing in $V$, guaranteeing a unique root.

**Scalar solver:** `SolveSlipRatePsi()` (`dieterich_ruina.hpp:~350`) uses
Brent's `zeroIn` (ported from Tandem).

**Vector solver:** `SolveSlipRateVectorPsi()` (`dieterich_ruina.hpp:413-431`):
1. Compute $|\boldsymbol{\tau}| = \sqrt{\tau_\text{dip}^2 + \tau_\text{strike}^2}$

2. Call scalar solver to get $|V|$

3. Decompose: $\mathbf{V} = -(|V| / |\boldsymbol{\tau}|) \, \boldsymbol{\tau}$ (anti-parallel, matching Tandem)

```cpp
void SolveSlipRateVectorPsi(const real_t tau_vec[2], real_t psi,
                             real_t sigma_n, real_t eta, real_t a,
                             real_t V_vec[2]) const
{
   real_t tau_abs = sqrt(tau_vec[0]*tau_vec[0] + tau_vec[1]*tau_vec[1]);
   real_t V_abs = SolveSlipRatePsi(tau_abs, psi, sigma_n, eta, a);
   V_vec[0] = -(V_abs / tau_abs) * tau_vec[0];
   V_vec[1] = -(V_abs / tau_abs) * tau_vec[1];
}
```

### 7.5 Pre-stress and Initial Conditions

**Pre-stress** $\tau_\text{pre}$ is computed per-DOF in `FaultGeometry::ComputeBP5Params()`
using `BP5Params::tau0_vec()` (`bp5_params.hpp:333-381`):

$$\tau_0 = \sigma_n \, a \, \text{arcsinh}\!\left(\frac{V_\text{init}}{2V_0} \exp\!\left(\frac{\psi_\text{ss}}{a}\right)\right) + \eta \, V_\text{init}$$

where $\psi_\text{ss} = f_0 + b \ln(V_0 / V_p)$ is the steady-state $\psi$ at plate rate.
In the nucleation zone, an extra $\Delta\tau = \Delta\tau_\text{factor} \cdot \eta \cdot V_\text{nuc}$
is added (SCEC Eq. 23).

**Initialization** follows Tandem's two-phase approach
(`seas_operator.hpp:184-241`):
1. `PreInit`: set $\text{slip} = 0$, $\psi = \text{placeholder}$ (steady-state at $V_\text{init}$)

2. Solve $K \mathbf{u} = \mathbf{b}$ with zero slip to get initial elastic traction

3. `Init`: compute $\psi$ from stress equilibrium using `InitialStatePsi()`

4. Verify: re-solve and check that stress equilibrium error $< 10^{-6}$


Total state size $= 3 \times N_\text{fault DOFs}$. The ODE integrates all components

## 8. Time Integration

### 8.1 Dormand-Prince RK45

**File:** `solver/time_stepper.hpp`

The code uses a Dormand-Prince 5(4) embedded Runge-Kutta method with 7 stages
and FSAL (First Same As Last). The 5th-order solution advances the state;
the 4th-order embedded solution provides a local truncation error estimate.

**Step structure** (`time_stepper.hpp:227-600`):

$$\mathbf{k}_0 = f(t, \mathbf{y}) \quad \text{(reused from previous step via FSAL)}$$

$$\mathbf{k}_s = f\!\left(t + c_s \, \Delta t, \; \mathbf{y} + \Delta t \sum_{j<s} a_{sj} \mathbf{k}_j\right), \quad s = 1, \ldots, 5$$

$$\mathbf{k}_6 = f(t + \Delta t, \; \mathbf{y}_\text{new}) \quad \text{(FSAL: becomes } \mathbf{k}_0 \text{ next step)}$$

$$\mathbf{y}_\text{new} = \mathbf{y} + \Delta t \left(b_1 \mathbf{k}_0 + b_3 \mathbf{k}_2 + b_4 \mathbf{k}_3 + b_5 \mathbf{k}_4 + b_6 \mathbf{k}_5\right)$$

$$\mathbf{e} = \Delta t \left(e_1 \mathbf{k}_0 + e_3 \mathbf{k}_2 + e_4 \mathbf{k}_3 + e_5 \mathbf{k}_4 + e_6 \mathbf{k}_5 + e_7 \mathbf{k}_6\right)$$

Each $f(\cdots)$ evaluation calls `SEASQuasiDynamicOperator::Mult()`, which
triggers a full domain solve.

### 8.2 Adaptive Step Size Control

The error norm uses $L^\infty$ (matching Tandem/PETSc `wnormtype infinity`):

$$\text{err}_i = \frac{|e_i|}{\text{atol} + \text{rtol} \cdot |y_i|}$$

$$\|\text{err}\| = \max_i \, \text{err}_i \quad \text{(global across MPI ranks)}$$

**Accept/reject decision:**
- If $\|\text{err}\| \le 1.0$: accept step, advance state and time
- If $\|\text{err}\| > 1.0$: reject step, shrink $\Delta t$

**Step size update:**

$$\text{factor} = S \cdot \|\text{err}\|^{-1/5} \quad \text{(5th order method)}$$

$$\text{factor} = \text{clamp}(\text{factor}, \; f_\text{shrink,min}, \; f_\text{growth,max})$$

$$\Delta t_\text{new} = \Delta t \cdot \text{factor}$$

After rejection, an extra reject safety factor ($0.5$) is applied.

**Default tolerances** (matching Tandem):
- $\text{atol} = 10^{-7}$
- $\text{rtol} = 10^{-50}$ (effectively pure absolute tolerance)
- $\Delta t_\text{min} = 10^{-6} \;\text{s}$, $\Delta t_\text{max} = 0.5 \;\text{year}$

### 8.3 V Guard

A stage-level velocity guard (`time_stepper.hpp:253-269`) rejects steps
if any intermediate RK stage produces slip rates exceeding
$V_\text{guard} \cdot V_{\max,\text{stage 0}}$. This catches CFL-violating steps before
they produce NaN.

```cpp
   // Element 1 is local, element 2 is a face-neighbor (ghost)
   const FiniteElement *fe1 = scalar_fes_->GetFE(FTr->Elem1No);
   auto *pfes = dynamic_cast<ParFiniteElementSpace*>(fes_.get());
   int nbr_idx = FTr->Elem2No - mesh_.GetNE();             // :1621
   const FiniteElement *fe2 = pfes->GetFaceNbrFE(nbr_idx);  // :1622

   // Compute both elvec1 and elvec2 (need elem2 for correct penalty),
   // but only accumulate elvec1 into the local RHS
   Vector elvec1, elvec2;
   slip_integrator.AssembleSlipFaceRHS(
      *fe1, *fe2, *FTr, delta_u_quad, elvec1, elvec2);     // :1626-1627

   // Only elem1 (local) goes into the global RHS vector
   Array<int> vdofs1;
   fes_->GetElementVDofs(FTr->Elem1No, vdofs1);
   for (int j = 0; j < vdofs1.Size(); j++)
   {
      int gj = vdofs1[j];
      if (gj >= 0) { rhs(gj) += elvec1(j); }              // :1634
      else { rhs(-1 - gj) -= elvec1(j); }                  // :1635
   }
}
```

Key detail: `AssembleSlipFaceRHS` computes `elvec2` for the ghost element
(needed for the correct penalty computation), but `elvec2` is discarded.
The neighbor rank computes the same face from its perspective, contributing
its own `elvec1`.

### 9.5 Traction Recovery: Face-Neighbor Data Exchange

Traction recovery requires displacement values from the ghost element.
This is obtained via `ExchangeFaceNbrData()` on the `ParGridFunction`:

```cpp
// elasticity_operator.hpp:4010-4052
ParGridFunction par_u(pfes);
par_u = displacement;
pfes->ExchangeFaceNbrData();
par_u.ExchangeFaceNbrData();                            // :4016 ← sends u to neighbors

for (int i = 0; i < fault_shared_faces_.Size(); i++)
{
   int sf = fault_shared_faces_[i];
   FaceElementTransformations *FTr =
      mesh_.GetSharedFaceTransformations(sf);            // :4021-4022

   // Elem1 (local): get DOFs from local par_u
   Array<int> vdofs1;
   fes_->GetElementVDofs(FTr->Elem1No, vdofs1);
   Vector u1_all(vdofs1.Size());
   par_u.GetSubVector(vdofs1, u1_all);                  // :4038

   // Elem2 (ghost): get DOFs from face-neighbor data
   int nbr_idx = FTr->Elem2No - mesh_.GetNE();          // :4041
   const FiniteElement *fe2 = pfes->GetFaceNbrFE(nbr_idx);
   Array<int> vdofs2;
   pfes->GetFaceNbrElementVDofs(nbr_idx, vdofs2);       // :4046
   const Vector &nbr_data = par_u.FaceNbrData();         // :4047
   Vector u2_all(vdofs2.Size());
   for (int j = 0; j < vdofs2.Size(); j++)
      u2_all(j) = nbr_data(vdofs2[j]);                  // :4051

   // Now compute traction using the same ComputeTractionAtQuadPoints
   // as interior faces — the integrator doesn't know about MPI
   trac_integ_sh.ComputeTractionAtQuadPoints(
      *fe1, *fe2, *FTr, u1_all, u2_all, delta_u_quad_sh,
      T_quad_sh, nullptr, &nl_q_sh);                     // :4157-4159

   // Project 3D traction to fault-local DOFs
   DGElasticityIPCombinedIntegrator::ProjectTractionToFaultDOFs(
      dim, 2, T_quad_sh, nl_q_sh, ir_sh2, nbf_sh, e_q_sh,
      tangents_sh, basis_sh.sign_flipped,
      trac_local_sh, qpd_sh);                            // :4175-4177
}
```

The key insight: once `u1_all` and `u2_all` are available, the traction
computation is **identical** to interior faces. All the MPI complexity is
in obtaining the ghost element's displacement.

### 9.6 Global Reductions

Several operations require global synchronization across all ranks:

**Error norm for adaptive time stepping** — the Dormand-Prince integrator
needs the global maximum error across all fault DOFs:
```cpp
// time_stepper.hpp (inside Step)
// err_norm = max over all local DOFs of |error_i| / (atol + rtol*|y_i|)
err_norm = mpi_->GlobalMax(err_norm);  // MPI_Allreduce(MAX)
```

**Maximum slip rate** — used for V-guard and output:
```cpp
// seas_operator.hpp
V_max = mpi_->GlobalMax(local_V_max);  // MPI_Allreduce(MAX)
```

**Probe output ownership** — each rank finds its closest fault DOF to
each station, then global MIN selects the owning rank:
```cpp
// io/bp5_parallel_output.hpp
MPI_Allreduce(local_dist, global_dist, ..., MPI_MIN);  // rank with min dist owns station
```

## 10. I/O and Benchmark Output

### 10.1 SCEC fltst Output

The primary output follows the SCEC SEAS benchmark format: one ASCII file
per probe station, with columns for time, slip, slip rate, shear stress, and
state variable.

**Output architecture** (`io/bp5_parallel_output.hpp`):
- `ParallelBP5BenchmarkOutput` uses distributed ownership: each rank locates
  stations on its local fault DOFs, and `MPI_Allreduce(MIN)` assigns ownership
  to the rank with minimum geometric distance.
- `Probe2DInterpolator` interpolates from face-averaged values or multi-DOF
  face basis functions to station coordinates.
- `ProbeOutput` (`io/probe_output.hpp`) handles individual file writing.

**Standard BP5 stations:** 10 on-fault stations at specific $(x_2, x_3)$ coordinates
along the fault surface (specified by the SCEC benchmark).

### 10.2 Checkpoint/Restart

`io/checkpoint.hpp` provides binary checkpoint of the state vector and time,
enabling restart of long earthquake cycle simulations.

### 10.3 ParaView/VTK Output

Optional diagnostic VTK output of displacement, boundary attributes, and
fault parameter distributions ($a$, $\tau_\text{pre}$, $V_\text{init}$).

## 12. How to Add a New Feature

### Adding a New Friction Law

1. Create `friction/my_friction.hpp` inheriting from `FrictionLaw`

2. Implement `FrictionCoefficient()`, `SolveSlipRate()`, and $\psi$-space variants

3. In the BP5 driver, replace `DieterichRuinaFriction` with your class

4. The rest of the pipeline (domain solve, traction recovery) is unchanged

### Adding a New Output Quantity

1. Decide where the quantity lives: fault DOFs (`rate_state_fault.hpp`) or
   domain DOFs (`elasticity_operator.hpp`)

2. Add a getter method to the appropriate operator class

3. In `bp5_parallel_output.hpp`, add a column to the probe output format

4. In the time loop, extract and write the quantity

### Adding a New Benchmark Problem

1. Create `config/my_params.hpp` following `bp5_params.hpp` pattern

2. Create a driver in `tests/verification/` following `bp5_verification_full.cpp`

3. Choose the domain operator (`ElasticityDomainOperator` for 3D,
   `AntiplaneDomainOperator` for 2D antiplane)

4. Set `SlipComponents` template parameter ($1$ for 2D, $2$ for 3D)

5. Wire up the parameter functions ($a(\mathbf{x})$, $L(\mathbf{x})$, $\tau_\text{pre}$, etc.) in `FaultGeometry`

## 13. Known Limitations and TODOs

- [ ] The stiffness matrix $K$ is assembled once and cached. This assumes the
      mesh and material properties do not change. For problems with
      evolving geometry or nonlinear materials, $K$ would need reassembly.
- [ ] The friction solver uses Brent's method (guaranteed convergence but
      not optimal speed). Newton-Raphson with Brent fallback could be faster.
- [ ] The BR2 method path uses face-averaged (single-DOF) fault discretization
      while the IP path supports multi-DOF per face. BR2 multi-DOF is not implemented.
- [ ] Off-fault station output (displacement at interior points away from
      the fault) is partially implemented but not fully tested in parallel.
- [ ] No dynamic (fully inertial) mode -- only quasi-dynamic with radiation damping.
- [ ] The $\psi$-space state evolution (`AgingLawPsi`) is used for BP5 but the
      transformation is handled inside the `RateStateFaultOperator` rather than
      being a separate evolution law class.
